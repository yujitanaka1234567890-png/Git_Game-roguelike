次元ローグライク（仮）

HP
精神
ログ（新しい順・スクロールで過去も見られる。下線の技名はクリックで説明）
操作
  • 矢印：移動・攻撃
  • Shift＋矢印2つ同時：斜め
  • Shift＋矢印1つ：ダッシュ（Shiftを離すと止まる）
  • スペース：足踏み
  • I：持ち物（T で投げる）
  • 階段の上で ↓↓：降りる
  • R を2回：冒険をあきらめる
  • .（ドット）：分隊への指示（人型の仲間を隊長に独立行動させる／呼び戻す。分隊と同じ部屋にいる時だけ）
  • 3：3D ⇔ 2D　V：ドット絵 ⇔ 文字
  • ＋／－：カメラを寄せる・引く（3D）
  • マウスホイール：3D画面の拡大・縮小
  • N：全体マップの大きさ（非表示・小・中・大）
  • M：効果音オン ⇔ オフ
見方
  • 左上の点 = 進化段階
  • 黄色い枠と「!」= 敵の技の溜め中
  • 青い枠 = 仲間の技の溜め中
  • 青い下地・青い四角 = 仲間（ぶつかると入れ替わる）
  • 橙の四角 = 分隊の仲間（独立行動中）
  • 体力ゲージ：緑 = 仲間、赤 = 敵
  • 精神 = ダンジョンにいると少しずつ減る。同じ階に長居すると速く減る（広い階ほど長く居られる）。0になると毎ターン2ダメージ（0が続くと10ターンごとに倍）。50%で遠吠え・25%でささやき
  • 紫の枠の中に立つ仲間 = はぐれた仲間（ぶつかる・乗ると救出）
  • 最下層はボス部屋（倒すと帰還のゲートが現れる）
  • 3D表示では左上に全体マップ（水色＝自分・青＝仲間・橙＝分隊・赤＝敵・黄＝アイテム・紫＝はぐれた仲間）
拠点での操作
  • 矢印で歩く（Shift＋矢印2つで斜め）
  • 牧場の仲間にぶつかる：話しかける
  • ▣ 収納箱：持って行く道具を選ぶ
  • 掲 掲示板：連れて行く仲間を選ぶ・救出隊を送る
  • ♥ 交配小屋：2体から新しい仲間を生み出す
  • 図 図鑑：出会ったモンスターを調べる
  • 碑 記録の石碑：続きから遊ぶための「記録の呪文」
  • ∩ 門に乗る：行き先を選んで出発
  • ウィンドウ：↑↓で選び Enter・スペースで決定、Esc で閉じる
  • 3：3D ⇔ 2D　V：ドット絵 ⇔ 文字　M：効果音
  • ＋／－・マウスホイール：3D画面の拡大・縮小
  • N：全体マップの大きさ（3D）
