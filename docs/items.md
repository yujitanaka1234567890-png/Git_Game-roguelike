# アイテム仕様書（要件を書く場所）

アイテムの効果・レア度について「こうしたい」という要件は、このファイルの表の **「要望」列** か、下の **「要望メモ」** に書いてください。
Claude がここを読んで、コードに反映します（反映したら表の説明も更新します）。

## どのファイルに何が書いてあるか

| やりたいこと | ファイル |
|---|---|
| 名前・説明文・回復量などの数値・レア度（rarity）・分類 | `js/items.js` の `types` |
| 使った時の効果の中身（回復・閃光・札など） | `js/items.js` の `effects`（投げた時は `throwEffects`） |
| 武器の装備・眠り・技封じ・守り・**ボスへの効き方** | `js/equip.js`（ボスの耐性の数値は `js/config.js` の `bossResist`） |
| 銃・杖（方向を選んで撃つ）の効果 | `js/shoot.js` |
| レア度ごとの出やすさ | `js/config.js` の `itemRarities` |
| 1階に落ちている数 | `js/config.js` の `dungeon.minItems / maxItems` |
| 別の世界で拾った品の効き目の読み替え | `js/data/worlds.js` の `DIMENSION_RULES` |
| 見た目（ドット絵） | `js/data/item_sprites.js` |

## レア度と出やすさ

| レア度 | 名前 | 出やすさ（spawn） |
|---|---|---|
| ★ 1 | よく見る | 10 |
| ★★ 2 | 少しめずらしい | 5 |
| ★★★ 3 | めずらしい | 2.5 |
| ★★★★ 4 | とてもめずらしい | 1 |
| ★★★★★ 5 | 幻 | 0.3（今は該当なし） |

強い・便利な物ほどレア度を高くして、出にくくしています。

## ボスへの状態の効き方（js/config.js の bossResist）

- 弱体（技封じ＝静寂の札・ひるみ＝グローブ・放逐の杖）：**効かない**
- 眠り（夢見の杖）：**最大2ターン**
- 状態異常（毒・麻痺・出血など。将来追加）：**ターン数が半分**（最低1ターン）。状態異常を作る時は `Game.equip.statusTurns(相手, "ailment", ターン数)` で実際のターン数を決める
