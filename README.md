# 次元ローグライク（仮）

ブラウザで遊べる、ターン制ローグライク × モンスター収集ゲームです。
ランダムに生まれるダンジョンを潜り、倒したモンスターを仲間にして拠点に連れ帰り、育て・交配し、次の冒険へ。

## 遊び方

- **ブラウザで開く**：`index.html` を開くだけで遊べます（インストール不要・サーバー不要）。
- セーブは自動です（ブラウザの保存領域に、拠点の牧場・倉庫などを記録します。外部には送信しません）。

### 操作

| 操作 | キー |
|---|---|
| 移動・攻撃 | 矢印キー |
| 斜め移動 | Shift ＋ 矢印2つ同時 |
| ダッシュ | Shift ＋ 矢印1つ（Shift を離すと止まる） |
| 足踏み | スペース |
| 持ち物 | I（Enter 使う ／ T 投げる ／ D 置く） |
| 階段・脱出口 | その上で ↓ を2回 |
| 冒険をあきらめる | R を2回 |
| ドット絵 ⇔ 文字表示 | V |
| 効果音 オン ⇔ オフ | M |

拠点では歩いて、牧場の仲間に話しかける（連れて行く仲間を選ぶ）・収納箱・交配小屋・救出の掲示板・門を使います。

## 主な仕組み

- ランダム生成ダンジョン、視界（部屋全体／通路は周囲だけ）、ターン制の戦闘
- 倒した敵が確率で仲間に（レア度で確率が変わる）。仲間も成長・進化し、技を使う
- 生きて帰れば仲間は牧場へ、持ち物は倉庫へ。倒れると新しい仲間とははぐれる（救出可能）
- 交配、救出隊の派遣、精神力（長居するとダンジョンに取り込まれる）
- 複数のダンジョンと「世界」（次元変換の土台）

## 素材・権利について

- **画像・音声の外部素材は一切使っていません。**
  - ドット絵はすべてこのゲームのために手で描いたオリジナル（`js/data/sprites.js` にドットの配置として記述）。
  - 効果音はブラウザの音声合成機能（Web Audio API）でその場で波形を作って鳴らしています（録音データなし）。
- モンスター・アイテム・技・地名などの名前はすべてオリジナルです。
- 文字はお使いの環境の標準フォントで表示しています（フォントファイルは同梱していません）。

## 開発者向け

- 構成と仕様：`CLAUDE.md`、開発の段取り：`docs/roadmap.md`、仕様のメモ：`docs/design_notes.md`
- モンスター・技・ダンジョン・交配表などのデータ：`js/data/`
- 管理者用のモンスター図鑑（データの一覧と設定ミスのチェック）：`admin/bestiary.html`
- 開発には AI コーディング支援ツール（Claude Code）を使用しています。
