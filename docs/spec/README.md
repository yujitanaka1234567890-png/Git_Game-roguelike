# 仕様書の使い方（まとめて修正を頼む仕組み）

1つずつチャットで頼む代わりに、**ここのファイルを書き換えてから、セッションに「仕様書を反映して」と一言だけ送る**やり方です。

| ファイル | 中身 |
|---|---|
| [monsters.md](monsters.md) | モンスター全種（能力・レア度・技・進化・出る場所） |
| [skills.md](skills.md) | 技（範囲・威力・予兆の文） |
| [items.md](items.md) | アイテム（レア度・効果・武器の数値・ボスへの効き方） |
| [requests.md](requests.md) | 新しいアイテム・モンスター・仕組みなど、表にない要望の置き場 |

## 書き方（3通り。どれを使ってもよい）

1. **値を書き換える**：`- HP: 8` → `- HP: 10` のように、数字や文をそのまま直す。
2. **「要望:」に書く**：`- 要望: もう少し硬くして、名前の響きを可愛く` のように文章で書く。数値が決まっていなくても大丈夫です。
3. **新しいもの・大きな変更**：[requests.md](requests.md) の「未対応」に `- [ ] 〇〇` の形で1行ずつ足す。

名前を変える時も、見出しの名前を直すだけで大丈夫です（カッコの中の英字 ID は変えないでください。目印に使います）。

## 手順

1. GitHub のページでファイルを開き、右上の鉛筆（✏️ Edit）で書き換えて「Commit changes」。
   （まとめて何か所でも、何回コミットしても大丈夫。）
2. セッションに **「仕様書を反映して」** と送る。
3. Claude が実装し、仕様書を最新の状態に作り直して（「要望:」は空に戻ります）コミットします。
   何を直したかは、コミットの差分（GitHub の「Files changed」）で確認できます。

## Claude がやること（参考）

- `git log` / `git diff` でユーザーが書き換えた所を探す。さらに `node tools/spec_gen.js 一時フォルダ` で今のゲームのデータから仕様書を作り、`docs/spec` と比べて、ユーザーが変えた値をすべて拾う。
- 空でない「要望:」と、requests.md の `- [ ]` を全部拾う。
- あいまいな所・既存作品に似てしまう所だけ、まとめて1回だけ質問する。
- 実装したら `node tools/spec_gen.js` で仕様書を作り直し、requests.md の対応した行を「完了」へ移す（日付つき）。
