## ゲーム仕様
- **次元変換のルール**：例）レーザーガン（SF）→ 魔法世界では何になり、何を消費するか（弾薬→MP など）。世界×アイテムカテゴリの対照表が必要。
- **交配の組み合わせ**：系統（種族タグ）ベースで「同系統のみ可」＋例外の特殊組み合わせ表、が有力。
- **救出隊の成功率**：レベル・知能・派遣階層から計算。失敗時は「手ぶらで帰還」か「救出隊もロスト」か未定。
- **必殺技のバランス**：理不尽にならないよう、予備動作（カウントダウン表示）と対策アイテムを用意。

## 権利・オリジナリティ
- 名称（アイテム・モンスター・技・地名など）はすべてオリジナル。既存作品の名前は使わない。
- ゲームの一般的な仕組み（ターン制・ランダムダンジョン等）は著作権で保護されない考え方が一般的だが、名前・文章・絵・音楽などの「表現」は保護されるので流用しない。
- 特許：ゲームの仕組みに関する特許は国内外に存在し得る。一般公開・収益化の前に、主要システム（仲間化・救出・次元変換など）について専門家への相談や特許検索を検討する。

## システム
- **ファイル分割**：マップ生成／戦闘計算／セーブ処理などを別ファイルに（CLAUDE.md参照）。
- **セーブ**：拠点データ（仲間・お金）は LocalStorage。フェーズBで実装。
- **素材**：ぴぽや、ザ・マッチメイカァズ等のフリー素材。利用規約（クレジット表記・再配布可否）を導入時に確認。
- **公開先**：第一候補 GitHub Pages（無料・Git連携）。代替 unityroom / itch.io / Vercel。
